# AI Mock Interview Platform

## 🚀 Overview

This is a full-stack AI-powered mock interview platform where users can practice interview questions and receive automated feedback with scoring.

## 🛠 Tech Stack

* Frontend: React (Vite)
* Backend: Node.js, Express
* API: RESTful APIs
* AI: Mock AI feedback system

## ✨ Features

* Dynamic interview questions
* Answer submission system
* AI-based feedback (mock)
* Score calculation (per question + overall)
* Clean UI with feedback cards

## ⚙️ How to Run

### Backend

cd server
npm install
npm run dev

### Frontend

cd client
npm install
npm run dev
